================================================================================

Las pruebas UAT requieren un ambiente que replique producción pero con uso
limitado en tiempo (típicamente 2-4 semanas de sprint). Se recomienda:
- Infraestructura idéntica a producción pero con menor capacidad
- Datos de prueba (subset de producción, 10-20% del volumen)
- Encender recursos solo durante horario de pruebas (8-10 hrs/día laborables)
- Destruir el ambiente al finalizar el ciclo de pruebas

RECOMENDACIONES PARA UAT:
─────────────────────────
1. Usar Terraform workspaces para separar UAT de producción:
   terraform workspace new uat
   terraform workspace select uat

2. Variables específicas para UAT (terraform.tfvars.uat):
   environment          = "uat"
   redshift_base_capacity = 8    (en vez de 32)

3. Programar encendido/apagado con EventBridge + Lambda:
   - Encender Redshift a las 8:00 AM
   - Apagar (pause) a las 6:00 PM
   - No ejecutar fines de semana

4. Datos de prueba:
   - Usar aws s3 sync con --exclude para copiar subset
   - Anonimizar datos sensibles con Glue DataBrew
   - Mantener volumen en 10-20% de producción

5. Al finalizar ciclo UAT:
   terraform workspace select uat
   terraform destroy  → Elimina todo, costo cae a $0

================================================================================
TIPS PARA REDUCIR COSTOS
================================================================================

1. S3: Usar lifecycle rules para mover datos viejos a Glacier ($0.004/GB)
2. Athena: Convertir datos a Parquet + particionar (ahorro 30-90%)
3. Redshift: Habilitar auto-pause (no cobra cuando está idle)
4. Lambda: Usar ARM/Graviton2 (20% más barato)
5. EKS: Usar Spot Instances para nodos (ahorro 60-90%)
6. Glue: Usar auto-scaling de DPUs y job bookmarks
7. Bedrock: Usar batch inference (50% descuento) cuando no es real-time
8. SageMaker: Apagar notebooks fuera de horario, usar Spot Training
9. General: Usar Reserved Capacity / Savings Plans (ahorro 20-40%)
10. API Gateway: Usar HTTP APIs en vez de REST APIs (70% más barato)
