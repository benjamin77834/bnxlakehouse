Descripcion de cada capa

1. Fuentes Externas

Origenes de datos que alimentan la plataforma. Pueden ser APIs REST de terceros, bases de datos transaccionales (MySQL, PostgreSQL, Oracle), dispositivos IoT que envian telemetria, archivos planos que se depositan via SFTP, o sistemas que emiten eventos en tiempo real.

2. Ingesta

API Gateway + Lambda: Reciben datos en linea (APIs, webhooks, IoT) y los escriben directamente en Bronze.
MSK Kafka: Bus de eventos para streaming de alta velocidad. Productores publican eventos y consumidores (Lambda, EKS) los procesan en tiempo real.
EKS: Jobs de extraccion pesados (replicacion de BDs, ETL custom con Spark).
S3 Landing: Punto de aterrizaje exclusivo para cargas batch u offline (archivos CSV, Parquet, JSON que llegan por SFTP o upload manual). Lambda los valida y mueve a Bronze.

3. Data Lakehouse (Bronze / Silver / Gold)

Bronze (Raw): Datos tal cual llegan, sin modificar. Se organizan por fecha (year/month/day). Sirven como fuente de verdad inmutable.
Silver (Curated): Datos limpios y estandarizados. Se aplican reglas de calidad, deduplicacion, tipado correcto y joins entre fuentes. Formato Parquet particionado.
Gold (Augmented): Datos enriquecidos y agregados, listos para consumo directo. Tablas de hechos y dimensiones, KPIs precalculados, features para ML.
Glue ETL Jobs: Transformaciones Spark/Python que mueven datos entre capas.
Glue Crawlers: Descubren automaticamente los schemas de los archivos en S3 y los registran en el catalogo.
Glue Data Catalog: Repositorio central de metadatos. Define tablas, columnas, tipos y particiones. Lo consultan Athena, Redshift Spectrum y SageMaker.
Amazon Athena: Motor SQL serverless para consultas ad-hoc directamente sobre S3. Paga solo por datos escaneados.

4. Data Warehouse

Redshift Serverless: Almacen de datos columnar optimizado para consultas analiticas complejas, dashboards de BI y reportes ejecutivos. Soporta SQL estandar, se conecta a herramientas como Tableau, Power BI, QuickSight. Consume datos Gold via COPY o Spectrum (consultas federadas sobre S3).

5. IA Generativa / Machine Learning

SageMaker Studio Unified: Entorno de desarrollo para data scientists. Notebooks Jupyter, experimentos de ML, exploracion visual de datos, MLflow integrado.
SageMaker Training: Infraestructura gestionada para entrenar modelos a escala (CPU o GPU). Soporta TensorFlow, PyTorch, XGBoost, y custom containers.
SageMaker Endpoints: Modelos desplegados para inferencia en tiempo real con auto-scaling. Sirven predicciones via API.
Bedrock - Modelos Fundacionales: Acceso a Claude (Anthropic), Titan (Amazon), Llama (Meta), Mistral para tareas de NLP, generacion de texto, resumen, clasificacion.
Bedrock Knowledge Bases (RAG): Indexa documentos de Gold en un vector store y permite hacer preguntas con contexto. El modelo busca informacion relevante antes de responder.
Bedrock Agents: Orquestadores que combinan modelos fundacionales + herramientas (APIs, bases de datos) para ejecutar tareas complejas de forma autonoma.

6. Capa de Salida / Serving

API Gateway REST: Punto unico de entrada para consumidores. Expone endpoints seguros con autenticacion, rate limiting y caching.
Lambda Serving Gold: Funcion que consulta datos Gold (via Athena o S3 directo) y los devuelve formateados al consumidor.
Lambda Serving ML: Proxy que envia requests a SageMaker Endpoints o Bedrock y devuelve predicciones/respuestas generadas.
Consumidores: Aplicaciones web, moviles, dashboards de BI, microservicios, otros sistemas que consumen datos y predicciones del data lake.

7. Observabilidad

CloudWatch Dashboards (7 tableros):
- General: Vista ejecutiva de salud del data lake.
- Ingesta: Landing processor, MSK Kafka throughput y consumer lag.
- ETL: Glue jobs duracion, bytes procesados, crawlers, tablas en catalogo.
- Analitica: Athena datos escaneados y tiempos, Redshift RPUs y conexiones.
- IA/ML: SageMaker invocaciones y latencia, Bedrock tokens y modelos.
- Serving: API Gateway requests, latencia p99, errores 4xx/5xx.
- Costos Unificado (separado): Gasto total, desglose de 16 servicios (Redshift, S3, Lambda, API GW, Glue, Athena, MSK, SageMaker, Bedrock, Neptune, EKS, Macie, KMS, WAF, CloudWatch, ECR), proxies de consumo por hora, estado de presupuestos, remediaciones ejecutadas, findings de Macie, requests bloqueados por WAF.

Alarmas criticas (SNS): Lambda errores, Glue failures, Redshift capacity, API 5xx, MSK disco, budget excedido, PII detectada.
Logs centralizados: Todos los Lambda, Glue jobs y MSK con retencion de 30 dias.

8. Seguridad

KMS (Key Management Service): Llave de encriptacion gestionada con rotacion automatica anual. Encripta datos en S3, Redshift, Glue. Todos los servicios del data lake tienen acceso.
WAF (Web Application Firewall): Protege API Gateway contra ataques. Rate limiting (2000 req/5min por IP), bloqueo SQL Injection, y reglas comunes de OWASP.
GuardDuty: Deteccion continua de amenazas. Monitorea S3 (accesos anomalos), Kubernetes (audit logs), y malware en EBS.
CloudTrail: Auditoria completa de todas las acciones API en la cuenta. Logs almacenados en S3 con validacion de integridad.
AWS Config: Evalua compliance de la infraestructura. Reglas: S3 debe tener encriptacion, S3 no debe ser publico. Registra cambios en configuracion.

9. ECR - Repositorios de Imagenes

Kubernetes (EKS):
- eks-services: Microservicios del data lake (APIs internas, workers)
- eks-jobs: Jobs batch de procesamiento y extraccion
- eks-ingestion: Contenedores de ingesta de datos

Agentes IA / ML:
- ai-training: Imagenes custom para entrenamiento de modelos (PyTorch, TensorFlow)
- ai-inference: Contenedores optimizados para servir modelos en SageMaker endpoints
- ai-agents: Agentes autonomos que combinan modelos + herramientas + memoria
- ai-pipelines: Pipelines de ML (feature engineering, evaluacion, deploy)

ETL:
- etl-custom: Contenedores Spark/Python custom para Glue jobs especializados

Seguridad: Todas las imagenes se escanean al push (vulnerabilidades), encriptadas con KMS, y lifecycle policy elimina imagenes sin tag a los 7 dias.

10. Control de Costos

AWS Budgets: Presupuestos mensuales por servicio (Total, Redshift, Lambda+API, Storage). Alertas al 50%, 80% y 100% del budget via SNS.
Lambda de Remediacion: Se dispara automaticamente cuando se excede el budget. Acciones disponibles:
- pause_redshift: Pone capacity a 0 (Redshift deja de cobrar)
- throttle_lambda: Reduce concurrencia de Lambdas de serving a 1
- stop_all_non_essential: Pausa Redshift + detiene Lambdas de serving
- notify: Solo notifica sin actuar

Alarmas de costo: Monitorean el gasto estimado cada 6 horas. Si Redshift o Lambda superan 90% del budget, se dispara la remediacion.

11. Multi-Cuenta (AWS Organizations)

Estrategia de cuentas separadas para aislamiento total entre ambientes. Cada cuenta tiene su propia facturacion, IAM, y red. Habilitado con enable_multi_account = true.

Sandbox: Experimentacion libre, SCP restringe a 1 sola region, datos efimeros.
UAT: Pruebas de aceptacion con datos anonimizados de produccion.
PreProd: Replica exacta de produccion para validacion final antes de deploy.
Produccion: Ambiente productivo con todos los controles de seguridad y compliance.

SCP (Service Control Policies): Politicas que restringen lo que cada cuenta puede hacer (ej: sandbox solo puede usar us-east-1).

12. Proteccion de Datos (PII / Confidencial)

Amazon Macie: Escanea automaticamente los buckets Bronze, Silver y Gold semanalmente buscando PII: tarjetas de credito, SSN, emails, telefonos, pasaportes, llaves AWS. Genera findings y dispara alarma si encuentra datos sensibles.

Bedrock Guardrails: Filtro activo en todos los modelos de IA generativa. Configurado para:
- BLOQUEAR: SSN, tarjetas de credito, llaves AWS, pasaportes, licencias de conducir
- ANONIMIZAR: emails, telefonos, nombres, IPs (reemplaza con [REDACTED])
- FILTRAR: contenido de odio, insultos, sexual, violencia

Flujo de proteccion:
1. Datos llegan a Bronze → Macie escanea semanalmente
2. Si Macie detecta PII → alarma critica + notificacion al equipo
3. Glue ETL aplica transformaciones de anonimizacion en Silver
4. Gold solo tiene datos limpios/anonimizados
5. Bedrock Guardrails filtra PII en tiempo real en GenAI

Alarma: Si Macie detecta cualquier PII, se dispara alerta critica inmediata via SNS.

13. Lambda Functions del Proyecto

El data lake tiene 5 funciones Lambda, cada una con un proposito especifico:

landing-processor (main.tf)
Valida archivos que llegan al bucket Landing, los copia a Bronze con prefijo de fecha (year/month/day) y dispara el Glue Crawler para actualizar el catalogo. Se activa automaticamente via S3 Event Notification.

serving-gold (outputs_serving.tf)
Sirve datos de la capa Gold a consumidores via API Gateway. Consulta S3 Gold directamente o via Athena y devuelve resultados formateados en JSON.

serving-ml (outputs_serving.tf)
Proxy de inferencia que recibe requests del API Gateway y los envia a SageMaker Endpoints o Bedrock. Devuelve predicciones y respuestas de modelos de IA a los consumidores.

cost-remediation (cost_control.tf)
Se dispara cuando una alarma de presupuesto se activa. Puede pausar Redshift (capacity=0), throttle Lambdas de serving (concurrency=1), o detener todos los servicios no esenciales.

daily-cost-report (cost_control.tf)
Se ejecuta todos los dias a las 8 AM UTC via EventBridge. Consulta AWS Cost Explorer, calcula gasto diario, acumulado mensual, proyeccion y desglose por servicio. Envia reporte por email a la lista de distribucion via SNS.

pwa-api (pwa_amplify.tf)
Backend de la app movil PWA. Consulta Cost Explorer y CloudWatch en tiempo real, devuelve JSON con gasto total, por servicio, alarmas activas. Desplegada en API Gateway.

Tips para Reducir Costos

  1. S3: Lifecycle rules para mover datos viejos a Glacier ($0.004/GB)
  2. Athena: Convertir datos a Parquet + particionar (ahorro 30-90%)
  3. Redshift: Habilitar auto-pause (no cobra cuando idle)
  4. Lambda: Usar ARM/Graviton2 (20% mas barato)
  5. EKS: Usar Spot Instances para nodos (ahorro 60-90%)
  6. Glue: Auto-scaling de DPUs y job bookmarks
  7. Bedrock: Batch inference (50% descuento) cuando no es real-time
  8. SageMaker: Apagar notebooks fuera de horario, Spot Training
  9. General: Reserved Capacity / Savings Plans (ahorro 20-40%)
  10. API Gateway: Usar HTTP APIs en vez de REST APIs (70% mas barato)
